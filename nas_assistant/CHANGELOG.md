# Changelog

## 1.0.0

First stable release.

- Pictures that can't be decoded show no thumbnail instead of causing a server error
- This changelog, and a clear note in the README about the permissions the add-on asks for

## 0.33.0

- Act on what you picked: move, add to a collection, favorite or delete, next to download
- What comes back from Recently deleted is again in the collections and favorites it was in

## 0.32

- Select many files and photos (all, by month, by date) and download them in one .zip
- On phones the Select button shows its label

## 0.31

- Videos in the sidebar, for your space and the family
- A long-lived code for app store reviewers

## 0.30

- Disks come and go freely: an unplugged disk stays chosen and is taken back when it returns
- Folder sizes
- An unreadable disk is never treated as blank
- Eject pauses the TV media server on its own

## 0.26 to 0.29

- Cleanup: find duplicates and similar photos
- Small files upload hundreds at a time
- Disk health (SMART) with warnings
- A gallery of tens of thousands of photos opens at once

## 0.20 to 0.25

- Watch on the TV: photos, videos and slideshows
- TVs of the house: a DLNA media server for Family
- Uploads that don't give up, with an upload panel, and folders up and down
- Security fixes and automated tests
- Sort every list by name, size, date added or date created

## 0.14 to 0.19

- Disks page, a second disk as backup or extra storage, and a storage pool
- Collections and safe eject
- Disk plug and play
- Other files on the disk

## 0.9 to 0.13

- iCloud-style welcome page
- Nightly backup to a second disk
- Background uploads from the iPhone, and pairing phones with a one-time QR code

## 0.1 to 0.7

- First version of the add-on, with a guided disk setup
- Photo gallery and Apple-style look
- Files by type, rename and move
- Works with protection mode on
- Multilingual UI and Recently deleted
